Télécharger Jarvis

Installation pour Windows 10 et 11. Jarvis est gratuit les 7 premiers jours, ensuite vous choisissez un plan mensuel.

Télécharger Jarvis

Version 3.153.0 · 197 MB

Windows 10 et 11 (64 bits)

Lancez le programme d’installation

Ouvrez le fichier téléchargé Jarvis-Setup.exe. Si « Windows a protégé votre ordinateur » s’affiche, cliquez sur Informations complémentaires puis sur Exécuter quand même.

Autorisez l’installation

Windows demande une fois l’autorisation. L’installation prend environ une minute, puis Jarvis démarre tout seul.

Saisissez votre nom

Pendant les 7 premiers jours, vous avez tout Jarvis gratuitement. Vous saisissez la clé de licence reçue par e-mail via J’ai une clé de licence ou plus tard dans Jarvis.

Le programme d’installation ne se lance pas ? Si Windows indique qu’il a été bloqué par le Contrôle intelligent des applications, le bouton Exécuter quand même n’apparaîtra pas – cette protection de Windows 11 ne laisse passer que les programmes signés par leur éditeur et n’autorise aucune exception pour un programme. Ouvrez Sécurité Windows → Contrôle des applications et du navigateur → paramètres du Contrôle intelligent des applications, choisissez Désactivé et relancez le programme d’installation. Laissez-le désactivé, sinon Windows pourrait bloquer Jarvis lui-même.

Jarvis télécharge et installe lui-même les versions suivantes quand vous vous éloignez de l’ordinateur. Il vérifie au passage la signature et n’installe donc que ce que j’ai publié.

Vous n’avez pas encore de licence ? Tarifs. Je vous aiderai volontiers pour l’installation : apoliak@apoliak.online.
